# 文档编写 02 模板适配与大纲

`doc-template-outline` 用于基于客户模板和资料解读结果，生成适合软件项目文档的目录、大纲和章节写作说明。

## Usage

在 Codex 中直接调用：

```text
$doc-template-outline
```

常见用法：

```text
使用 $doc-template-outline，基于客户模板和资料解读结果生成文档大纲。
```

## Output

输出通常包括：

- 模板结构分析
- 章节目录和标题建议
- 每章写作要点
- 缺失章节或模板适配建议
- 进入正文编写阶段的条件

## Repository Layout

```text
doc-template-outline/
  README.md
  SKILL.md
  agents/
    openai.yaml
```
