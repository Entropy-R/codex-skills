# 三段开发 02 实现方案设计

`solution-design` 用于基于需求理解与澄清结果，把需求转换成清晰、可执行的工程实现方案。

## Usage

在 Codex 中直接调用：

```text
$solution-design
```

常见用法：

```text
使用 $solution-design，基于第一阶段输出和我的补充回答生成工程实现方案。
```

## Output

输出通常包括：

- 目标和范围
- 模块与数据流设计
- 接口、数据结构和依赖说明
- 边界条件和失败处理
- 任务拆解与测试建议
